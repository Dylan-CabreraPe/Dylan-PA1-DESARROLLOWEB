HTML, CSS y JavaScript:

Son los tres pilares fundamentales del desarrollo web que trabajan juntos para crear páginas web dinámicas e interactivas.

HTML se encarga de la estructura y el contenido, CSS del diseño y la presentación, y JavaScript de la interactividad y la funcionalidad.

Definiciones:

HTML

Es el lenguaje marcado que define la estructura y el contenido de una pagina web

CSS

Es el leguaje de estilos que se usa para controlar la presentación de una pagina web

JavaScript

Es un leguaje de programacion que permite agregar funcionalidad interactivaa una pagina web
